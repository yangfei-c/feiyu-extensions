# Feiyu Extensions（飞羽浏览器扩展合集）

作者：YangFei

本仓库用于存放飞羽系列原创浏览器扩展。每个扩展在独立子目录中维护源码、安装说明与功能演示。

## 扩展列表

| 扩展 | 简介 | 当前版本 |
| --- | --- | --- |
| [飞羽 · arXiv 论文助手](./feiyu-arxiv-copilot/README.md) | 为 arXiv 论文提供结构化导读、双语翻译、选区问答和阅读记录导出。 | v2.2.3 |

## 安装方式

- **Chrome 应用商店**：[打开「飞羽 · arXiv 论文助手」详情页](https://chromewebstore.google.com/detail/gmpagaiebchoilchbhdbpgjjbbefipcl)，点击「添加至 Chrome」。
- **GitHub 手动安装**：[下载 v2.2.3 安装包](https://github.com/yangfei-c/feiyu-extensions/releases/download/v2.2.3/feiyu-arxiv-copilot-v2.2.3.zip)并解压，然后按[手动安装步骤](./feiyu-arxiv-copilot/README.md#本地手动安装)加载扩展。

仓库将持续更新已有扩展，并陆续加入其他浏览器扩展。
